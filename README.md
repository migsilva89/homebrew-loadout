# homebrew-loadout

Homebrew tap for [Loadout](https://loadout.migsilva.dev) — the Mac app that shows and
manages what your coding assistants load: skills, commands, subagents, plugins and MCP
servers, with real usage.

## Install

```sh
brew install --cask migsilva89/loadout/loadout
```

Or tap first, then install:

```sh
brew tap migsilva89/loadout
brew install --cask loadout
```

## Update

```sh
brew upgrade --cask loadout
```

## Uninstall

```sh
brew uninstall --cask loadout
```

Add `brew uninstall --zap --cask loadout` to also remove the app's settings and cached data.

## Requirements

macOS 15 (Sequoia) or later. The app is signed with a Developer ID certificate and
notarised by Apple, so it opens without a Gatekeeper warning.

Source code and releases: [github.com/migsilva89/loadout](https://github.com/migsilva89/loadout)
